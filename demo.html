02 / The challenge

Space mission design is a system of trade-offs.

Students need a way to experiment with mission objectives, payloads, spacecraft systems, launch capacity, power, mass, communications and budget—not just read about them.

Too much mass

The selected launch vehicle cannot carry the spacecraft.

Not enough power

Subsystem demand can exceed available generation.

Limited resources

Every engineering choice affects cost and mission readiness.

03 / Our solution

Design a satellite. See the consequences.

Players take the role of a mission director and configure an Earth-observation satellite using a guided, browser-based simulation.

04 / How the game works

Five spacecraft systems. One launch decision.

Spacecraft bus

Core platform and structure.

Scientific payload

Earth-observation instrument.

Power system

Solar generation and electrical demand.

Communications

Data capacity for mission return.

Thermal control

Basic equipment temperature management.

Launch vehicle

Payload capacity must fit spacecraft mass.

05 / Engineering logic

Mission readiness is checked before launch.

The game recalculates the design as components change, then blocks launch until every training constraint passes.

BudgetCredits used vs limit
MassSatellite vs launch capacity
PowerGeneration vs demand
CommsCapacity vs mission need

The mission score reports the proportion of checks passed. It is a teaching mechanic, not a real-world mission certification score.

06 / NASA data connection

Use environmental data to teach solar context.

The prototype includes a server-side connection to NASA POWER daily point data for all-sky surface shortwave downward radiation (ALLSKY_SFC_SW_DWN).

Location

Chennai, India · 13.0827° N, 80.2707° E

Parameter

Daily solar radiation, reported by NASA POWER in kWh/m²/day.

Purpose

Environmental context for solar-energy learning—not live spacecraft telemetry.

NASA POWER Daily API documentation: power.larc.nasa.gov/docs/services/api/temporal/daily/
07 / Impact, technology & acknowledgement

Make mission engineering approachable.

MissionCraft helps beginners understand that spacecraft design is a connected engineering problem: improve one subsystem, and the other constraints may change.

Frontend

HTML, CSS and JavaScript

Backend & storage

Vercel Node.js Functions and Supabase Postgres (optional cloud sync); browser local save fallback.

Future work
